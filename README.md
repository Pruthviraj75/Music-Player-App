# **Music Player App** 🎵

![HTML](https://img.shields.io/badge/HTML-5-orange)
![CSS](https://img.shields.io/badge/CSS-3-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)

The **Music Player App** is a web-based music streaming application inspired by **Spotify**, developed with **HTML, CSS, and JavaScript**. This project showcases a dynamic user interface and essential features for music playback, providing a seamless and enjoyable music experience.

---

## **Features** 🎶
- **Play/Pause**: Control music playback with play and pause buttons.
- **Next/Previous Track**: Navigate between songs effortlessly.
- **Progress Bar**: Visualize and control the playback progress.
- **Volume Control**: Adjust the volume with a slider.
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices.
- **Dynamic UI**: Sleek and modern user interface inspired by Spotify.

---

## **Technologies Used** 💻
- **Frontend**:
  - HTML5
  - CSS3
  - JavaScript (ES6)
- **Tools**:
